# Bayesian EMS Step-by-Step

零公式、按順序學習的救護研究 Bayesian 入門網站。

## 特色
- 12 個循序漸進步驟
- 每步只有一個主要學習目標
- EMS / EMT / 安全搬運 / HBM × TTM 案例
- p=.09 與 posterior probability 的詳細拆解
- Prior、Posterior、MCMC、R-hat、ESS、multilevel 白話解釋
- 最後才進入 R / brms
- 瀏覽器 localStorage 記錄學習進度

## GitHub Pages
1. 建立 repository
2. 上傳 `index.html` 至根目錄
3. Settings → Pages
4. Deploy from a branch → main / root
5. Save
