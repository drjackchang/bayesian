STEP 0｜先有感覺

你其實每天都在做 Bayes，只是沒有叫它 Bayes

學完這一步：你會知道 Bayesian 最核心的動作就是「新資訊出現後，更新判斷」。

想像你接到一位胸痛病人。剛到現場時，你可能只覺得「有可能是 ACS，但也可能不是」。接著你拿到年齡、病史、皮膚狀況、12 導程 ECG、生命徵象，每一個新資訊都會讓你的判斷往上或往下調。

一開始胸痛 → 有一些懷疑
→
新資訊病史、ECG、生命徵象
→
更新後現在更懷疑或更不懷疑
Bayesian 的核心不是公式：「我原本怎麼想」＋「現在看到什麼」→「我現在怎麼更新」。

先不要急著學名詞

後面你會看到 Prior、Posterior、Likelihood。先把它們暫時翻成：「原本」、「新資料」、「更新後」。這樣就夠了。

如果新 ECG 結果出現後，你完全不改變原本判斷，最不符合哪個概念？
STEP 1｜機率語言

「機率」不是只有一種說法

學完這一步：你不會把 Bayesian 機率只理解成「重複很多次後的比例」。

統計小白常被教成：「30% 就是同樣事情做 100 次，大約發生 30 次。」這種說法對很多情況有用，但 Bayesian 還會用「機率」描述我們對未知事情的不確定程度。

長期頻率的語言
「這類病人裡約 10% 有某疾病。」

在很多相似病人中，大約有多少比例發生。

Bayesian 不確定性的語言
「根據目前資訊，這位病人有病的機率約 70%。」

描述我們對這一個未知狀態的確定程度。

重要：後面說「介入效果為正的 posterior probability 91%」時，指的是我們對未知效果方向的不確定程度，不是把同一個研究重做 100 次會有 91 次顯著。
STEP 2｜自然頻率

不用公式：用 1000 個人看懂「檢查陽性 ≠ 真的有病」

學完這一步：你會用實際人數理解事前機率如何影響更新後機率。

以下是教學假設情境，不是特定 ECG 裝置的實測數據：1000 位胸痛病人中，先假設 1% 真的是目標疾病；某判讀工具敏感度 80%、特異度 97%。

①

1000 人中，原本真的有病：約 10 人

②

10 位有病者中，工具抓到 80%：約 8 個真陽性

③

剩下 990 人其實沒病

④

特異度 97% 代表約 3% 沒病者仍會陽性：約 30 個偽陽性

⑤

所有陽性者約 38 人，其中真的有病只有 8 人

✓

所以看到陽性後，真的有病約 21%，不是 80%，也不是 97%。

你剛剛做的其實就是更新：從原本 1% 的懷疑，看到陽性證據後，更新到約 21%。
STEP 3｜互動練習

自己拖拖看：事前機率改變，陽性後的可信度會怎麼變？

學完這一步：你會直覺感受到 base rate / prior probability 的力量。
結果為陽性後，真的有病的機率 21.2%
真陽性 / 10008
偽陽性 / 100030
真陰性 / 1000960
偽陰性 / 10002
試試看：先不要動敏感度和特異度，只把事前機率從 1% 拉到 30%。看看「同一個工具陽性」之後，結果會差多少。
STEP 4｜最重要的橋樑

從「病人有沒有病」跨到「研究介入到底有沒有效」

學完這一步：你會突然發現臨床 Bayes 和研究 Bayesian 是同一個骨架。
臨床判斷
未知的是：病人到底有沒有疾病
原本：先有一個懷疑程度
新證據：ECG / FAST / 病史
更新後：疾病機率改變
⇄
研究推論
未知的是：真正介入效果有多大
原本：先有合理效果範圍
新證據：這次收集的研究資料
更新後：效果的機率分布
這就是整個課程最重要的一句話：臨床 Bayes 在更新「疾病的未知狀態」；研究 Bayes 在更新「效果的未知大小」。
STEP 5｜研究 Bayesian 三核心

Prior、Data、Posterior：現在才正式叫出名字

學完這一步：你能用自己的話講清楚三個名詞。
Prior 先驗

一句話：看這次資料以前，你認為「合理效果可能在哪裡」。

安全搬運課程可能有幫助或沒幫助，但不先相信一堂短課可以造成誇張到不合理的巨大改變。
不是：研究者自己先決定答案。
Likelihood / Data 資料提供的證據

一句話：這次收集到的資料，把哪些可能效果推得比較合理。

介入組平均改善較多，但個體差異也很大，所以資料雖偏正向，仍然有不確定性。
不是：問卷裡多一題叫 likelihood。
Posterior 後驗

一句話：Prior 跟這次資料更新完後，現在對效果的完整判斷。

大部分可能效果落在正向，但仍保留一小部分接近 0 或負向的可能性。
不是：一個單一答案或「Bayesian p-value」。

小白 Prior 怎麼做？

第一篇研究先從「弱資訊 Prior」開始最容易：正負方向都允許，但不太相信極端大效果。再用不同合理 Prior 做 sensitivity analysis，看結論會不會被 Prior 綁死。

不要做：先看完資料，再一直調 Prior，直到結果變漂亮。
STEP 6｜最容易搞錯

p = .09，為什麼 Bayesian 還可能說「正向效果機率 91%」？

學完這一步：你能向別人解釋：91% 不是 1 − .09，也不能只靠 p=.09 反推出來。
先記住：91% 絕對不是用 1 − 0.09 算出來。p-value 和 posterior probability 問的是不同問題。

先用固定的教學研究

假設某安全搬運介入研究，觀察到介入組比對照組多改善 +0.45 分，資料的不確定性使傳統雙尾檢定約為 p=.09。

傳統 p-value 比較接近問

「如果真正效果完全是 0，像現在這麼偏離 0 或更極端的資料，會不會很少見？」

Bayesian posterior probability 問

「給定 Prior、模型和這次資料後，真正效果落在 0 以上的機率是多少？」

互動示範｜同一份資料，Prior 改變時會怎麼更新？

這是一個簡化的常態近似教學器，用來建立直覺，不是所有 Bayesian 模型都能用這個小工具代替。

傳統雙尾 p-value.091
Posterior：效果 > 091.1%
Posterior：效果 > 實務門檻65.6%
負向 / 無效果實務重要門檻較大正向效果
正確說法：「傳統分析未達常用 .05 門檻；在指定 Prior 與模型下，posterior 顯示效果為正的機率約 91%，而超過預先定義實務重要門檻的機率約 66%。」
錯誤說法：「因為 p=.09，所以有效機率就是 91%。」
STEP 7｜不要再二分

Credible interval 與「實務重要門檻」

學完這一步：你會看方向、大小、不確定性，而不是只問「跨不跨 0」。
方向大部分效果在正向還是負向？
大小正向只有一點點，還是大到值得介入？
不確定性可能範圍很集中，還是很寬？
Credible Interval 可信區間

白話：在目前 Prior、模型與資料之下，真正效果很可能位於的一段範圍。它的工作是呈現不確定性，不是創造另一個「有 / 沒有顯著」門檻。

為什麼要先定義「實務重要」？

如果改善 +0.01 分，數學上仍然是「大於 0」，但實務上可能完全不值得投入教育成本。因此 Bayesian 很適合直接問：效果超過我們事先定義的有意義門檻，其機率有多高？

門檻要有臨床、教育或政策理由，最好在分析前定義，不要看到結果後才挑。
STEP 8｜電腦怎麼找 Posterior

MCMC 不用會推導：把它想成多組搜救隊

學完這一步：你會知道 Chain、R-hat、ESS、PPC 分別是在檢查什麼。
Chain

一組搜尋隊的探索路線。

R-hat

不同搜尋隊最後有沒有找到相似區域。

ESS

真正有效、沒有一直重複的探索資訊夠不夠。

PPC

模型自己模擬的資料，像不像你真的收集到的資料。

小白最低要求：模型「跑完」不等於模型「跑好」。至少要看收斂、有效抽樣量，以及 posterior predictive check。

STEP 10｜問卷案例

HBM × TTM 安全搬運：Bayesian 到底能回答什麼？

學完這一步：你能把理論構面、Outcome、Bayesian model 串成研究問題。
HBM：為什麼會想改變？
易感性嚴重性效益障礙自我效能行動線索
→
TTM：改變到哪一階段？
前意圖意圖準備行動維持
→
實際安全搬運行為
行為分數遵從頻率

Bayesian 問法

  • 自我效能越高，進入較後 TTM stage 的機率有多高？
  • Barriers 的負向效果有多少 posterior probability？
  • 某種 HBM profile 的 EMT，落在 Action / Maintenance 的預測機率是多少？
  • 效果是否大到值得設計特定教育介入？
重點：問卷不用設「Bayesian 題目」。Bayesian 是分析階段如何把理論構面與 Outcome 建模。
STEP 11｜前後測案例

介入組＋對照組：真正核心不是「各自有沒有顯著」

學完這一步：你知道前後測最重要通常是兩組「變化幅度是否不同」。
介入組
前測 → 後測 → 3 個月
對照組
前測 → 後測 → 3 個月

如果同一個人被測很多次，這些資料不是彼此獨立。Bayesian mixed / multilevel model 可以把「個人 baseline 不同」甚至「每個人的變化速度不同」放進模型。

比 p-value 更直覺的結果

  • 介入組比對照組改善更多的 posterior probability 是多少？
  • 改善超過預先定義實務門檻的機率是多少？
  • 3 個月時效果仍維持的機率是多少？
  • 不同受試者反應差異有多大？
不要只做：介入組前後 p<.05、對照組 p>.05，然後說兩組效果不同。真正要比較的是「改變幅度」。
STEP 12｜EMS 資料結構

病人 → EMT → 分隊 → 消防局：為什麼要 Multilevel？

學完這一步：你會知道什麼叫「資料巢狀」，也知道 random effect 不是亂數。
病人
EMT / Paramedic
分隊
消防局 / EMS Agency

同一分隊的 EMT 可能接受相同訓練、主管文化、器材配置與 SOP，因此資料彼此更像。把所有人假裝成完全獨立，可能會低估不確定性。

Random Effect 隨機效果

白話：讓不同人、分隊或機構可以有自己的起點，必要時也可以有自己的變化軌跡。

Bayesian multilevel 的額外優勢：小樣本分隊不容易因為偶然幾個成功個案就被估得過度極端，會有合理的 partial pooling。
STEP 13｜最後才碰 R

R / brms：不要背程式，先把每一行翻成研究語言

學完這一步：你能看懂最基本的前後測 Bayesian mixed model 在指定什麼。
library(brms)

fit <- brm(
  safe_score ~ group * time + (1 | id),
  data = dat_long,
  family = gaussian(),
  chains = 4
)

summary(fit)
pp_check(fit)
程式片段白話翻譯
safe_score我要解釋的 Outcome：安全搬運分數。
group * time我要看組別、時間，以及「兩組變化是否不同」。
(1 | id)同一個人有自己的 baseline，不把每一筆測量當成不同人。
family = gaussian()我把 Outcome 當作合理的連續數值來建模。
chains = 4讓多條 MCMC 路線確認 posterior 是否探索穩定。
pp_check()檢查模型模擬出來的資料像不像真實資料。

你的 HBM × TTM 會長得不一樣

fit_ttm <- brm(
  ttm_stage ~ susceptibility + severity + benefits +
              barriers + self_efficacy + cues,
  data = dat,
  family = cumulative("logit"),
  chains = 4
)

這裡只是讓你先看懂「模型語法如何對應研究問題」。真正分析時還需要正式設定 Prior、處理尺度、缺失值與模型診斷。

STEP 14｜跑完之後

模型檢查、論文怎麼講，以及總測驗

學完這一步：你知道一篇 Bayesian 分析至少要檢查與報告哪些東西。

四個最低限度檢查

R-hat不同 chains 是否收斂到相似區域。
ESS有效 posterior 資訊量是否足夠。
Trace plot探索有沒有卡住、漂移或分離。
Posterior Predictive Check模型能不能合理重現真實資料樣貌。

結果不要寫成統計密碼

不建議只寫：β = 0.xx，95% CrI = …
比較好：在控制其他 HBM 構面後，自我效能越高，進入較後期 TTM stage 的可能性較高；posterior 大多落在正向。以預測機率呈現時，高自我效能者進入 Action / Maintenance 的機率明顯高於低自我效能者。

  • Chains、iterations、收斂診斷
  • Posterior estimate 與 credible interval
  • 你真正關心的 posterior probability / prediction
  • Sensitivity analysis
  • Posterior predictive check
