1. 先學貝氏的語言，不先學數學

你原本認為
「大概會怎樣」
→
看到這次研究資料
→
更新成
「現在比較相信什麼」

Bayesian 的核心其實只有這件事：新的資料出現後，更新我們對未知事情的判斷。

例：你原本認為「安全搬運訓練應該有幫助，但不太可能讓所有人都大幅改善」。收完 200 位 EMT 的前後測後，資料會把這個原本的看法往某個方向更新。最後得到的不是「顯著／不顯著」而已，而是一整個「效果可能在哪裡」的分布。

2. Bayesian 名詞大辭典

不背英文也沒關係，但你必須知道論文裡這些詞在說什麼。可直接搜尋關鍵字。

Prior 先驗分布
一句話

在看這次資料以前，對「效果大概可能落在哪裡」的合理想法。

救護例子
你不會先相信一堂 2 小時安全搬運課可以讓行為分數暴增 10 倍，所以你先把「非常誇張的效果」視為比較不可能。
常見誤解
不是「研究者自己亂猜答案」。好的 prior 要有理由，而且可以做敏感度分析。
Likelihood 似然
一句話

這次真正收集到的資料，對各種可能效果提供多少支持。

救護例子
你看到介入組多數 EMT 的安全搬運分數提升，而對照組幾乎沒變，這批資料會把「介入有效」的可能性往上推。
常見誤解
它不是另一份問卷，也不是一個要單獨背的分數；它是模型如何「看待資料」的一部分。
Posterior 後驗分布
一句話

看完這次資料後，你現在對效果的最新判斷。

救護例子
分析後你可能得到：訓練效果大多落在正向，而且達到實務有意義改善的可能性也不低。
常見誤解
Posterior 不是一個單一數字；它是一整個「可能效果長什麼樣」的分布。
Credible Interval 可信區間
一句話

在目前模型與資料下，我們認為真正效果很可能位於的一段範圍。

救護例子
如果安全搬運訓練的改善幅度大部分落在小幅到中度改善之間，可信區間會把這段不確定性呈現出來。
常見誤解
不要把傳統 confidence interval 和 Bayesian credible interval 當成完全相同概念。
Posterior Probability 後驗機率
一句話

看完資料後，某個你關心的條件成立的機率。

救護例子
「訓練能改善安全搬運行為的機率是多少？」或「改善超過我們認為有實務意義門檻的機率是多少？」
常見誤解
不是把 p-value 換一個名字；它回答的問題不一樣。
Uncertainty 不確定性
一句話

我們承認研究結果不是百分之百確定，而是有一段可能範圍。

救護例子
樣本只有 40 人時，效果估計通常會比較模糊；有 800 人時，可能會更集中。
常見誤解
區間很寬不是「分析失敗」，有時只是資料真的沒有提供足夠資訊。
MCMC 馬可夫鏈蒙地卡羅
一句話

電腦反覆探索各種可能的參數值，最後拼出 posterior 長什麼樣。

生活比喻
像派出好幾組搜救隊在山區找可能的位置；如果每組最後都探索到相似區域，你比較放心沒有漏掉重要地方。
常見誤解
你不需要會自己手算 MCMC，初學者只需要知道它是電腦怎麼把 posterior 找出來的。
Chain 抽樣鏈
一句話

MCMC 的其中一條探索路線。

救護比喻
像同時派 4 組人從不同起點去找同一個失蹤者。如果最後都聚到相似區域，表示探索比較可信。
常見誤解
4 chains 不是「做 4 次研究」，而是讓電腦從不同起點確認答案是否一致。
R-hat 收斂診斷指標
一句話

看不同 chains 最後是不是已經找到差不多的地方。

救護比喻
4 組搜救隊最後回報的區域彼此差很大，代表「還沒找穩」；R-hat 就是在提醒你這件事。
常見誤解
不是效果大小，也不是 p-value。它只是「模型跑得穩不穩」的檢查。
ESS 有效抽樣數
一句話

雖然電腦抽了很多次，但真正提供多少「不重複資訊」。

生活比喻
你問 100 個人，但其中 80 個都只在重複同一句話，那有效資訊量就不像真的有 100 份獨立意見。
常見誤解
它不是你研究的受試者人數。
Posterior Predictive Check 後驗預測檢查
一句話

讓模型自己「生成一批假資料」，看看像不像你真正觀察到的資料。

救護例子
如果模型說大部分 EMT 安全搬運分數都集中在很高分，但真實資料其實兩極化，表示模型可能沒有抓到資料結構。
常見誤解
模型成功跑完不代表模型就適合；PPC 是必做的合理性檢查。
Sensitivity Analysis 敏感度分析
一句話

故意換幾種合理設定，看結論會不會被某一個設定綁死。

救護例子
把 prior 設得稍微保守、稍微寬鬆，各跑一次；如果「自我效能是重要因素」的結論都差不多，結果就更穩健。
常見誤解
不是一直換到找到自己喜歡的結果。
Weakly Informative Prior 弱資訊先驗
一句話

不強迫答案，但先排除太離譜的效果。

救護例子
你允許安全搬運訓練有正有負，但先不認為一堂課會讓行為分數改變到完全不合理的程度。
常見誤解
不是「沒有 prior」。Bayesian 一定有 prior，只是 prior 可以很寬鬆。
Multilevel Model 多層次模型
一句話

資料不是每一筆都彼此獨立，而是「人包在人裡、分隊包在機構裡」。

救護例子
病人屬於某位 EMT、EMT 屬於某分隊、分隊屬於某消防局。這些層級可能一起影響結果。
常見誤解
不是因為模型「比較高級」才用，而是因為資料結構本來就有層級。
Random Effect 隨機效果
一句話

讓不同人、不同分隊、不同機構可以有自己的起點或變化方式。

救護例子
有些 EMT baseline 本來就比較高分；有些分隊安全文化特別強。模型可以容許這些差異存在。
常見誤解
「random」不是亂數，也不是說這些人隨便被抽到；它是統計模型的結構名稱。
Population-level Effect 群體層級效果
一句話

你真正想知道的整體趨勢，例如平均來說介入組是否比對照組改善更多。

救護例子
不管某一位 EMT 特別高分或低分，整體而言安全搬運課程是否有效。
常見誤解
在不同軟體或模型裡名稱可能不同，先理解概念比背名詞重要。
Ordinal Model 有序類別模型
一句話

結果有高低順序，但每一級之間不能假設完全等距。

救護例子
TTM 的前意圖期、意圖期、準備期、行動期、維持期有順序，但「前意圖→意圖」和「行動→維持」不一定是同樣距離。
常見誤解
看到 1、2、3、4、5 不代表它一定就是普通連續分數。
Logistic Model 二元結果模型
一句話

結果只有兩種主要狀態時使用。

救護例子
ROSC 有／沒有、插管成功／失敗、是否發生搬運傷害。
常見誤解
它不是只屬於傳統統計；Bayesian 一樣可以做 logistic model。
Linear Model 連續結果模型
一句話

結果是一個可以合理看成連續的分數或數值。

救護例子
安全搬運總分、知識分數、某些生理測量、經適當處理後的時間指標。
常見誤解
不是所有 1–5 Likert 題都應直接當 linear outcome；要看是單題還是構面分數及研究目的。
Interaction 交互作用
一句話

一個因素的效果，會不會因另一個因素不同而改變。

救護例子
介入組和對照組「隨時間改變的幅度」是否不同。前後測研究常關心的是這個，而不是只看兩組最後誰比較高。
常見誤解
不是把兩個變項相乘來「增加顯著性」，而是回答一個真正不同的研究問題。
Clinically Meaningful Threshold 實務／臨床意義門檻
一句話

不是「只要大於零就算有用」，而是先定義多大的改善才真的值得在實務上採用。

救護例子
你可以先定義：安全搬運行為分數至少增加某個幅度，才算值得單位投入教育成本。
常見誤解
門檻應該先有實務理由，不能看到結果後才選一個漂亮數字。

3. 傳統統計 vs 貝氏：不是誰取代誰

你在想的問題傳統統計常見語言Bayesian 常見語言
有沒有差？p-value、confidence intervalposterior、credible interval
效果是不是正的？間接透過檢定與區間解讀直接報「效果為正的 posterior probability」
效果夠不夠大？需另外定義 effect size / threshold可直接問「超過實務門檻的機率」
分隊、個體差很多？mixed model / GEEBayesian multilevel model 很自然
初學者不要陷入「Bayesian 比 p-value 高級」這種二分法。真正重要的是：你的研究問題適合什麼 estimand、資料結構是什麼、結果要怎麼讓臨床人員理解。

4. Prior 不用背公式：你只要會回答三個問題

① 我知道方向嗎？

如果不知道，就不要硬設正向或負向。

② 我知道合理大小嗎？

至少能不能排除「極端到不合理」的效果？

③ 結論會不會被 prior 綁死？

用 sensitivity analysis 檢查。

小白最安全的做法

先用弱資訊 prior：不偏向正或負，但不要允許非常離譜的效果太容易出現。然後用較寬鬆的設定再跑一次；如果結論差不多，你就更放心。

你不需要在問卷裡新增「Prior 題目」。Prior 是分析模型的設定，不是受試者回答的一部分。

5. Posterior 怎麼看？先看「方向、大小、不確定性」

方向

效果大部分是在正向還是負向？

大小

改善幅度只是微小，還是可能達到實務上有意義？

不確定性

結果集中，還是範圍很寬？

這三件事比只問「有沒有顯著」更適合拿來跟臨床團隊溝通。

6. MCMC：你不需要知道它怎麼推導，只要知道怎麼檢查

把 MCMC 想成「電腦派多組探索隊去找 posterior」。你要確定每一組最後都找到差不多的區域，而且探索量夠。

R-hat

大家有沒有找到同一區？

ESS

真正有效的探索量夠不夠？

PPC

模型生成的假資料像不像真的？

這三個名詞先學會，就足以避免「模型跑完就直接解釋」這種最常見錯誤。

8. HBM × TTM 安全搬運問卷，怎麼做 Bayesian？

最重要的不是先想「Bayesian 題目」，而是把理論構面和 outcome 定義清楚。

角色內容Bayesian 會問什麼
HBM predictors易感性、嚴重性、效益、障礙、自我效能、行動線索哪一個因素最可能推動行為改變？
TTM outcome前意圖→意圖→準備→行動→維持某種 HBM profile 落在較後階段的機率是多少？
實際行為 outcome安全搬運行為分數或頻率哪些因素真正和行為表現有關？
小白版重點：TTM 1–5 是「有順序的類別」，所以通常優先考慮 ordinal model；安全搬運總分如果合理視為連續分數，可以考慮 linear model。

9. 前後測研究：Bayesian 最值得拿來做什麼？

假設未來你的新研究是介入組與對照組，各自有前測、後測，甚至 3 個月追蹤。

同一個人
有多次測量
→
個人本來就不一樣
→
用 multilevel / mixed model
把個體差異放進模型

真正值得回答的是：

  • 介入組比對照組「改善更多」的機率是多少？
  • 改善幅度超過實務門檻的機率是多少？
  • 不同受試者反應差異有多大？
  • 效果到 3 個月是否仍可能維持？
前後測不要只做「介入組自己前後有差、對照組自己前後沒差」，真正核心通常是兩組「改變幅度」是否不同。

10. 多層次資料：EMS 研究特別常見

病人
→
EMT
→
分隊
→
消防局

如果忽略這些層次，就好像假設「同一分隊的 50 位病人」和「來自 50 個不同分隊的 50 位病人」資訊結構完全一樣，通常不合理。

Bayesian multilevel model 的優勢之一，是能把每一層差異一起納入，並避免小樣本分隊因為偶然幾個成功案例就被估得太極端。

11. 模型有沒有跑壞？小白只要先看這四件事

檢查白話問題如果怪怪的
R-hat不同探索隊有沒有找到相似答案？先不要解釋結果。
ESS有效探索量夠不夠？可能需要更多 sampling 或改善模型。
Trace plot探索路線有沒有卡住或漂移？檢查模型與 sampling。
Posterior predictive check模型模擬出來的資料像不像真資料？重新思考分布、結構或漏掉的變項。

12. 論文不要寫成統計密碼

最有用的 Bayesian 結果，應該讓臨床人員可以直接理解。

不好懂：「模型係數的 posterior median 為……」

更好懂：「在控制其他因素後，自我效能越高，進入較後期安全搬運行為階段的可能性明顯增加。模型顯示此關係大多為正向；以預測機率呈現時，高自我效能者進入行動／維持期的機率明顯較高。」

統計細節還是要報，但主文應先回答臨床問題。

13. R 可以學，但等你懂模型在做什麼再打程式

推薦路線：R + RStudio / Posit IDE + brms。你不需要先會原生 Stan。

第一個目標：不是「背程式」，而是知道每一行在指定什麼

library(brms)

fit <- brm(
  safe_score ~ group * time + (1 | id),
  data = dat_long,
  family = gaussian(),
  chains = 4
)

summary(fit)
pp_check(fit)
程式片段白話翻譯
safe_score我要解釋的結果：安全搬運分數
group * time我要看組別、時間，以及兩者的交互作用
(1 | id)同一個人有自己的 baseline，不把每筆資料當成完全獨立
chains = 4讓電腦從 4 條探索路線確認答案是否穩定
pp_check()檢查模型產生的資料像不像真資料
初學者不需要先學「公式」，但一定要學會「這行程式在對研究問題做什麼」。

14. 小白自我檢查：做到這些才算真的入門

我能不能用自己的話解釋 Prior？

不是背「先驗分布」四個字，而是能說：「看這次資料前，我對效果合理範圍的想法。」

我知道 Posterior 不是一個單一答案嗎？

要知道它是一整個可能效果的分布，包含不確定性。

我知道 credible interval 跟 confidence interval 不能直接當同一件事嗎？

如果知道，就已經跨過很多初學者常見誤區。

我知道 MCMC 不是我要手算的東西嗎？

對。你要會檢查 chains、R-hat、ESS、PPC，而不是推導演算法。

我知道前後測真正要看的是「改變幅度差異」嗎？

如果有介入組與對照組，通常重點不是各組自己有沒有顯著，而是兩組變化是否不同。

我知道模型要跟 outcome 類型與資料層級一起選嗎？

如果知道 continuous / binary / ordinal / repeated / clustered 的差異，就已經開始能自己選模型。
