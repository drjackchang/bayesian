0. 先建立直覺：貝氏不是「另一種題目」

同一份問卷、同一份 OHCA registry、同一份重複測量資料，都可以做傳統統計，也可以做 Bayesian。差別主要在模型與推論方式，不是問卷要出什麼「貝氏題」。

Prior
看資料前的合理範圍
＋
Likelihood
這次資料告訴你的事
→
Posterior
看資料後更新的機率分布

傳統結果

OR = 1.25，95% CI 0.96–1.63，p = .09

很容易被縮成「不顯著」。

Bayesian 結果

介入有益的機率 91%；達到預先定義臨床重要效果的機率 64%。

比較貼近臨床決策語言。

1. Prior 到底怎麼辦？

對初學者，先不要從「找一篇文獻把效果塞進 prior」開始。最穩健的第一步是：標準化 predictor ＋ 弱資訊先驗（weakly informative prior）＋敏感度分析。

實用預設：如果 HBM 各構面已轉成 z-score（平均 0、SD 1），可先從迴歸係數 Normal(0, 0.5) 開始，並用 Normal(0, 1) 做 sensitivity analysis。
Prior白話翻譯適合情境
Normal(0, 0.5)正負都有可能，但先不相信效果會大得離譜標準化問卷 predictor 的常用初學者起點
Normal(0, 1)比上面寬鬆，允許更大的效果敏感度分析或對效果尺度較不確定
文獻資訊 prior把之前研究的估計正式帶進來已有高度可比研究，而且你能說明轉換方式
方向性 prior例如「效益應該是正向」理論與先驗證據非常強；初學研究不必急著用
不要做：看完自己的結果後才挑一個能讓答案漂亮的 prior。Prior 應在主要分析前有理由地設定，並透明報告 sensitivity analysis。

2. 互動：資料如何把 Prior 更新成 Posterior

下面用最簡單的「成功率」例子。想像你在看某個救護訓練後的正確操作率。這不是你最後論文一定會用的模型，但它最容易建立直覺。

Prior 平均
50.0%
資料成功率
70.0%
Posterior 平均
66.7%

觀察：把 n 拉大，你會看到 posterior 越來越靠近資料；把 prior 強度拉大，prior 對 posterior 的影響會增加。

4. 範例：HBM × TTM「安全搬運行為改變」

問卷本身照正常方式設計。Bayesian 從分析階段開始。

4.1 建議資料架構

變項角色可能尺度
SusceptibilityHBM predictorLikert 構面分數
SeverityHBM predictorLikert 構面分數
BenefitsHBM predictorLikert 構面分數
BarriersHBM predictorLikert 構面分數
Self-efficacyHBM predictorLikert 構面分數
Cues to actionHBM predictorLikert 構面分數
TTM stage主要 outcome1–5 有序類別
Safe handling behavior次要 outcome連續/平均分數，或有序頻率

4.2 你真正可以問的 Bayesian 問題

  • 自我效能越高，進入較後面 TTM stage 的機率有多高？
  • Barriers 的負向效果有多大機率超過「值得介入」的門檻？
  • 哪個 HBM 構面最能改變 Action / Maintenance 的預測機率？
  • 某種 EMT profile（高風險認知但低自我效能）落在每個 TTM stage 的機率是多少？
如果 TTM 是 1–5 且確實具有順序，第一個入門模型通常是 Bayesian ordinal regression。如果同一受試者有多次測量，再加入受試者 random intercept，變成 Bayesian multilevel ordinal model。

5. 原本用 GEE 的資料，怎麼「改成 Bayesian」？

先記住：Bayesian multilevel model 並不是把 GEE 按一個「Bayes 開關」。兩者常回答相近問題，但 estimand 可能不同。
GEEBayesian multilevel / mixed model
常見目標population-averaged effectconditional / cluster-specific effect；亦可再用 posterior prediction 做 marginalization
重複測量關聯working correlation受試者/分隊 random effects 等完整機率模型
不確定性SE、CI、p-valueposterior distribution、credible interval、probability statements
小群集/稀疏資料可能較不穩合理 prior 可提供 regularization

5.1 原本如果是這種研究

例如：同一批 EMT 在 baseline、post-test、3 months、6 months 的安全搬運分數，原本用 GEE 比較時間與組別交互作用。

原 GEE
score ~ group × time
→
Bayesian mixed model
score ~ group × time + (1|id)

如果每個人的時間變化不同，還可考慮 random slope：(1 + time | id)。

5.2 最重要的公平比較

若要跟原 GEE 結果比較，不要只比「係數有沒有變」。先寫清楚兩個模型各自估的是什麼，再用 posterior marginal predictions / contrasts 產生接近 population-averaged 的比較量。

7. 軟體：R 可以嗎？可以，而且很適合

對救護研究者，我最推薦的入門路徑是 R + RStudio / Posit IDE + brms + Stan。brms 用很像一般迴歸的 formula 語法，背後用 Stan 做完整 Bayesian inference。

brms

最推薦給研究應用者。支援廣泛的 generalized、multilevel、multivariate models。

rstanarm

語法非常接近 glm / glmer，適合熟悉傳統 regression 的人。

bayesplot

畫 MCMC diagnostics 與 posterior predictive checks。

posterior

整理 posterior draws、R-hat、ESS 與摘要。

install.packages(c(
  "brms",
  "rstanarm",
  "bayesplot",
  "posterior",
  "tidyverse"

第一次安裝 Stan 生態系可能需要 C++ toolchain。Windows 通常需依目前 R 版本安裝對應 Rtools。若只是初學，可先把「能成功跑一個 brms 範例」當第一個里程碑。

8. R / brms：從你的 HBM × TTM 開始

8.1 先把 HBM 構面標準化

library(tidyverse)
library(brms)

hbms <- c("susceptibility", "severity", "benefits",
          "barriers", "self_efficacy", "cues")

dat <- dat %>%
  mutate(across(all_of(hbms), ~ as.numeric(scale(.x)),
                .names = "{.col}_z"))

8.2 TTM 1–5：Bayesian ordinal regression

dat$ttm_stage <- ordered(dat$ttm_stage, levels = 1:5)

priors <- c(
  prior(normal(0, 0.5), class = "b")
)

fit_ttm <- brm(
  ttm_stage ~ susceptibility_z + severity_z + benefits_z +
              barriers_z + self_efficacy_z + cues_z,
  data = dat,
  family = cumulative("logit"),
  prior = priors,
  chains = 4,
  iter = 4000,
  seed = 20260831
)

summary(fit_ttm)

8.3 同一人多次測量：Bayesian mixed model

fit_repeat <- brm(

  family = gaussian(),

9. 不是跑完就算了：Bayesian 模型要檢查什麼？

① R-hat

接近 1 是必要條件。看到明顯 > 1.01 就先檢查 sampling / convergence。

② Effective Sample Size

看有效 posterior draws 是否足夠。

③ Trace plots

不同 chain 應混合良好，不應卡住或漂移。

④ Posterior Predictive Check

模型生成的資料，能不能合理重現你真正觀察到的資料？

summary(fit_ttm)
plot(fit_ttm)
pp_check(fit_ttm)
初學者規則：沒有做 posterior predictive check，就不要急著解釋 posterior。

10. 論文結果怎麼寫，才不像在背 Bayesian 術語？

10.1 不只報「有/沒有」

推薦同時報：

  • posterior median / mean
  • 95% credible interval
  • 方向機率，例如 P(β > 0 | data)
  • 若有臨床門檻，再報 P(effect > clinically important threshold)

10.2 HBM × TTM 示範句

在控制其他 HBM 構面後，自我效能與較後期的 TTM stage 呈正向關聯；其迴歸係數的 posterior 有 98% 位於 0 以上。以預測機率呈現時，自我效能由 −1 SD 增加至 +1 SD，進入 Action/Maintenance 階段的預測機率由 XX% 增加至 YY%。

10.3 Prior 方法段示範

Continuous predictors were standardized before analysis. Weakly informative normal priors centered at zero were specified for population-level regression coefficients. Prior sensitivity analyses using wider normal priors were conducted to assess the robustness of posterior conclusions.

11. 已經用 GEE 發表過，可以把同一資料改成 Bayesian 再發嗎？

可以做再分析，但不代表一定足以成為一篇新的 original article。

比較有機會

實質新問題

例如原文只問「平均是否改變」，新研究改問個別軌跡、異質性、TTM stage transition、clinically meaningful probability，並採新的 model / estimand。

通常不夠

只把 p-value 換成 posterior

同一 outcome、同一 hypothesis、同一結論，只把 GEE 換成 Bayesian mixed model，通常新穎性不足。

透明度最低要求

  1. 新論文清楚引用原本 GEE 論文。
  2. Methods / cover letter 說明這是 secondary / re-analysis。
  3. 清楚列出「這篇跟原篇差在哪裡」。
  4. 不要把同一批資料包裝成一個全新的、未曾發表的 cohort。
  5. 投稿前看目標期刊對 overlapping publication / secondary analysis 的政策。
最好的重新發表策略不是「Bayesian 取代 GEE」，而是：Bayesian 讓你回答一個原本 GEE 沒有回答、而且對救護實務更重要的新問題。

12. 統計小白 FAQ

Q1：樣本小就一定要 Bayesian 嗎？

不是。Bayesian 不會憑空製造資訊。合理 prior 能 regularize，但資料非常少時 posterior 仍會很不確定。

Q2：Bayesian 就不用 sample size 嗎？

不是。仍需做設計與 precision / assurance / simulation 思考。差別在於規劃方式可以跟 posterior decision criteria 結合。

Q3：Prior 一定要來自上一份研究嗎？

不一定。初學者可以從 weakly informative prior 開始，再做 prior predictive check 與 sensitivity analysis。

Q4：Likert 1–5 可以直接做 Bayesian 嗎？

可以。單題 Likert 通常可考慮 ordinal model；多題形成構面後，若有合理量表建構，研究者也常使用構面分數做 regression。建模選擇應配合理論與資料尺度。

Q5：Bayesian 有沒有 p-value？

通常不需要把分析中心放在 p-value。你會看 posterior interval、方向機率、預測機率與臨床意義門檻。

Q6：我要學 Stan 語法嗎？

不一定。多數救護臨床與問卷研究，用 brms 已經可以走很遠。等你需要自訂 likelihood 或特殊模型時，再往原生 Stan 走。
